AI 服務

        

          
        


        

          
DeepSeek API

          

            
          

          
到 DeepSeek 開放平台 建立 API Key 後貼上。照片會傳到 DeepSeek 伺服器處理。費用估計每張約 NT$0.05 以內，實際以帳單為準。

        


        

          
OpenRouter API

          

            
            
          

          
到 OpenRouter 建立 API Key 後貼上。模型清單只列出能讀圖片的 DeepSeek 與 Qwen 模型（開啟設定時自動向 OpenRouter 更新）。照片會經 OpenRouter 傳給該模型的服務商處理，費用依模型而定。

        


        

          
Claude API

          

            
            
          

          
到 Anthropic Console 建立 API Key 後貼上。照片會傳到 Anthropic 處理。費用估計：Opus 5.5 每張約 NT$1 以內，Haiku 5.5 每張約 NT$0.1 以內，實際以帳單為準。

        

        
測試

        

          
          

        

        
API Key 只存在這支手機，只會傳給你選的服務商。AI 失敗時會自動改用本機辨識。

      


      
拍照

      

        
      

      
拍完照會先進入裁切畫面，開啟時會自動把四個角對到名片邊緣，你再微調就好；關閉時四個角從畫面四周開始。


      
備份與換手機

      

        
        
      

      
換手機時：在舊手機匯出備份，用 AirDrop、iCloud 雲碟或 Email 傳到新手機，在新手機打開 App 按「從備份檔還原」選這個檔案。已經有的名片不會重複。API Key 不會放進備份，新手機需重新填寫。


      
關於

      

        
名片資料存放只存在這支手機（不會上傳到 GitHub 或任何伺服器）

        
備份首頁右上「匯出」產生 CSV（Excel 用，不含照片）；設定頁「匯出完整備份」含照片，可用來換手機
